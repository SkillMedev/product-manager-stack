# Product Manager Stack

**Roadmaps, specs, sprints, and analytics — the PM’s full operating kit.** — built in-house by [Skill&nbsp;Me](https://skillme.dev).

Everything a product manager needs to plan and ship. Write roadmaps and specs, define personas, run sprints, set OKRs, read product analytics, map user flows, and write crisp tickets.

⭐ **If this is useful, star the repo** — it's how we gauge what to build next.

## Install

- **From the catalog:** [skillme.dev/pack/product-manager-stack](https://skillme.dev/pack/product-manager-stack) — install the whole pack into Claude in one step.
- **With the skills CLI:** `npx skills add aouellets/product-manager-stack`
- **Manually:** copy any `skills/<slug>/SKILL.md` into your Claude skills directory.

## Skills in this pack

- **[Product Roadmap](skills/product-roadmap/SKILL.md)** — Translates strategy into a time-based roadmap with themes, milestones, and trade-off notes.
- **[Technical Spec Writer](skills/technical-spec/SKILL.md)** — Writes engineering specs: background, requirements, non-goals, design, open questions.
- **[User Persona Builder](skills/user-persona/SKILL.md)** — Synthesizes research into personas with goals, frustrations, behaviors, and quotes.
- **[Sprint Planning](skills/sprint-planning/SKILL.md)** — Facilitates sprint planning — backlog refinement, capacity, commitment, and risk flags.
- **[OKR Builder](skills/okr-builder/SKILL.md)** — Objectives and Key Results that are ambitious, measurable, and actually tracked.
- **[Product Analytics](skills/product-analytics/SKILL.md)** — Sets up product analytics: event taxonomy, funnel tracking, cohort analysis.
- **[User Flow Mapper](skills/user-flow-mapper/SKILL.md)** — Maps complete user flows — happy path, error states, edge cases, and re-engagement.
- **[Jira Ticket Writer](skills/jira-ticket-writer/SKILL.md)** — Writes Jira stories with clear acceptance criteria, subtasks, and story point guidance.
